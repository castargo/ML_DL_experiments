# Полный список компетенций для эксперта в области Data Science и AI-разработки

## 1. Prompt‑инжиниринг

1. Написание простых запросов к LLM (single‑step prompts). 
2. Написание промптов с шаблонным и динамическим контекстом (system promt, user prompt, параметры).
3. Применение техник промптинга: few‑shot, zero‑shot, CoT, tree of thought, декомпозиции и т.д.
4. Знание параметров генерации LLM (max tokens, температура, top-k, top-p).
5. Понимание лимитов контекста LLM.  
6. Генерация структурированных ответов (Pydantic Output Schema).
7. Оптимизация промптов под задачу (тестирование промптов на разметке).
8. Выбор LLM для генерации: размер модели, reasoning, regress-тестирование.
9. Техники эволюции промптов.      
10. Использование методов knowledge‑grounding и in‑prompt embedding.     
11. Проектирование детерменированных LLM-пайплайнов.

## 2. Оптимизация работы с токенами

1. Понимание принципа работы токенизации (алгоритмы, типы, контекстное окно).
2. Знание инструментов учёта потребления токенов.
3. Умение посчитать стоимость использования API для конечного решения.
4. Умение оптимизировать стоимость запросов в LLM: выбор модели (small/big) по критерию цена‑качество, кэширование, обработка батчами и т.д.
5. Умение оптимизировать архитектуру решение для уменьшения расхода токенов.
6. Применение инструментов мониторинга и ограничение потребления токенов.

## 3. Работа с векторными базами данных / RAG

1. Способность назвать все компоненты RAG (векторная БД, эмбеддинги, ретвиверы, реранкеры и т.д.).
2. Понимание подходов к составлению документов, заголовков, мета-данных.
3. Знание подходов поиска: векторный, статистический, гибридный.
4. Векторные базы данных FAISS / Chroma / OpenSearch / PGVector / ...
5. Подбор оптимальной модели эмбеддингов (Sentence Transformers).
6. Реранжирование запросов перед этапом генерации.
7. Работа с запросом пользователя: контекст, перефразирование и т.д.
8. Выбор LLM для генерации ответа.
9. Использование LangChain и LangGraph для реализации RAG.
10. Оценка качества RAG: vtnhbrb поиска, генерации.
11. Понимание, что нужно выбрать для задачи: RAG, fine‑tuning или альтернативы.
12. GraphRAG.
13. AgenticRAG.

## 5. Разработка агентов

1. Понимание архитектуры ИИ-агента: восприятие (perception), рассуждение и планирование (reasoning/planning), действие (action/tool use).
2. Понимание отличий детерминированных LLM-пайплайнов (workflows) от агентных систем с динамическим графом выполнения.
3. Знание базовых паттернов построения агентов: ReAct (Thought → Action → Observation), Plan-and-Execute, Reflexion.
4. Понимание компонентной архитектуры агента: оркестратор, LLM, контекстное окно, внешняя информация, инструменты, безопасность, observability.
5. Владение фреймворками для разработки агентов: LangChain, LangGraph и т.д.
6. Разработка кастомных тулов для агентов: функции, API-обёртки, интеграция с внешними системами.
7. Знание и применение протокола MCP (Model Context Protocol) для стандартизации подключения инструментов.
8. Подготовка тестовых корзин для тестирования агента: сборка и анализ.
9. LLMaaJ для оценки качества: one-prompt, критерии, чек-листы и т.д.
10. Сборка тестовых кейсов на граничных случаях.
11. Внедрение observability: логирование всех вызовов LLM и инструментов, сбор трейсов, дашборды мониторинга.
12. Оценка качества агентов: метрики (accuracy, task completion rate, tool call accuracy), LLM-as-a-judge, регрессионное тестирование.
13. Обеспечение безопасности агентов: контроль доступов, детектирование prompt injection, маскирование PII, ограничение инструментов.

10. Разработка диалоговых систем и виртуальных ассистентов с мультимодальным вводом/выводом.
11. Подготовка мультимодальных датасетов (текст + изображение + аудио) для обучения и оценки.
12. Оценка качества мультимодальных моделей: метрики для разных модальностей, cross-modal alignment.
13. Оптимизация вычислительных ресурсов: снижение latency, настройка гиперпараметров, баланс качества и скорости.

## 9. Pre-training и пост-тренинг LLM (обучение с нуля и после обучения)

1. Понимание полного жизненного цикла LLM: pre-training → supervised fine-tuning → preference optimization (RLHF/DPO) → evaluation → deployment.
2. Знание архитектур современных LLM: трансформеры (encoder-only, decoder-only, encoder-decoder), механизм внимания, positional encoding.
3. Понимание Self-Supervised Learning: автокорелляционные задачи (Next Token Prediction, Masked Language Modeling), обучение на огромных объемах неразмеченных данных.
4. Алгоритмы токенизации: BPE, WordPiece, SentencePiece, управление размером словаря, особенности токенизации разных языков.
5. Подготовка данных для пре-тренинга: сбор, фильтрация, дедупликация, токенизация, создание датасетов для обучения.
6. Выбор и настройка архитектуры: плотные модели vs Mixture of Experts (MoE), размер модели, количество слоев, внимание, нормализация.
7. Понимание [MoE (Mixture of Experts)](https://newsletter.maartengrootendorst.com/p/a-visual-guide-to-mixture-of-experts): замена плотных слоев FFN на разреженные эксперты, Top-K routing, auxiliary loss for load balancing.
8. Масштабирование обучения (distributed training): Data Parallelism, Model Parallelism, Pipeline Parallelism, Expert Parallelism (для MoE), использование DeepSpeed, FSDP, Megatron-LM.
9. Знание scaling laws: оптимальное соотношение размера модели, размера датасета и вычислительных ресурсов; Chinchilla scaling laws.
10. Настройка гиперпараметров обучения: Learning Rate (косинусный распад), batch size, Adam/AdamW, weight decay, градиентное клиппирование.
11. Работа с вычислительными ресурсами: GPU-кластеры, управление памятью, mixed precision training (FP16/BF16), gradient checkpointing.
12. Мониторинг обучения: отслеживание loss, perplexity, gradient norm, анализ сходимости, ранняя остановка.
13. Понимание этапа Pre-training: учим модель предсказывать следующий токен на триллионах токенов → "knowledgeable but uncontrolled" модель.
14. Понимание этапа Alignment: превращение базовой модели в модель, следующую инструкциям и человеческим ценностям.
15. Знание методов Alignment: RLHF (Reinforcement Learning from Human Feedback), DPO (Direct Preference Optimization), Constitutional AI, Self-Instruct.
16. Понимание различий в alignment для reasoning-моделей: смещение фокуса с финального ответа на качество Chain of Thought, использование verification-based RL.
17. Знание Multi-Stage Alignment: SFT → DPO Step 1 → DPO Step 2 (разные этапы для разных целей).
18. Использование фреймворков для alignment: Hugging Face alignment-handbook, TRL (Transformer Reinforcement Learning).
19. Понимание Alignment Tax: неизбежное ухудшение общих способностей модели в процессе alignment, методы минимизации потерь.
20. Понимание Catastrophic Forgetting (катастрофическое забывание) в контексте дообучения на узкие задачи.
21. Методы борьбы с Catastrophic Forgetting: KL-регуляризация, Continual Learning, псевдо-повторение (rehearsal) пройденного материала, снижение Learning Rate.
22. Оценка качества обученных LLM: метрики (perplexity, accuracy, win rate, MT-Bench, AlpacaEval, MMLU, GSM-8K).
23. Сравнительный анализ моделей: бенчмарки (MMLU, GSM-8K, HumanEval, MATH, Arena-Hard), оценка reasoning и safety.
24. Квантизация весов: методы (GPTQ, AWQ, GGUF), влияние на качество и скорость инференса.
25. Умение проектировать пайплайны обучения: от данных до развертывания; итеративное улучшение через циклы SFT → DPO → evaluation.
